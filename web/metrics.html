How often is this tool wrong?

Every number on this page is written by a script in the project's eval/ folder and read from eval/results.json. Nothing is typed in by hand. Each one comes with its sample size and a 95% range, because the samples are small and the true rate could sit anywhere in that range.

Not measured

  • Whether Bluesky search finds the copies of a post in the first place. Only the comparison of two texts is tested.
  • Technique detection on video transcripts and on thread replies. Speech is looser than writing, so expect more false alarms there.
  • Accounts built to look human. Every bot in the sample says openly that it is one.
  • A real coordinated campaign. The copy test uses copies made by a script.

Run it yourself

python -m eval.run_similar                               # copy detection, no network
python -m eval.run_bots --refresh                        # bot-likeness, reads 120 public accounts
python -m eval.run_techniques --api https://davincicommit.tech   # techniques, spends AI credits

The scripts, the labelled accounts, the test texts and every single answer the detector gave (eval/predictions.json) are in the repository.
