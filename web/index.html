How it works

  1. Techniques. An AI model checks the post against 20 published persuasion techniques. A result is kept only if it quotes words that are really in the post.
  2. Bot-likeness. Posting rhythm, profile and text reuse give a suspicion score with reasons. It is not a probability.
  3. Copies. We search Bluesky for other accounts posting the same words. Matching text shows coordination, not automation.
  4. Live sources. We search the web for the post's main claim and read the pages in full. Each point quotes its source. It is a sample of the web, not a verdict.
  5. Thread. Every reply gets its own bot-likeness score. Replies scoring above 0.4 are also checked for techniques. Click a reply to analyse it in full.

Missing evidence is shown as "not enough data", never as a clean result. Built at Junction 2026 by The Da Vinci Commit.
